# Auto Layout v2 — User Requirements

작성일: 2026-06-01
목적: 감염병동 모듈 자동배치 툴의 다음 개발 방향을 사용자 요구사항 기준으로 압축 정리한다.

## 핵심 방향

현재 우선순위는 로봇 동선이 아니라 **병동/감염병 대응센터 배치 자체를 법·가이드라인·공간 논리에 맞게 안정적으로 생성하는 것**이다.

## 사용자 요구사항

### 1. 두 가지 생성 모드

#### A. 무그리드 모드 / 병상수 기반 자동 생성
- 사용자가 그리드를 직접 선택하지 않는 경우:
  - 병상수만 입력한다.
  - 툴이 필요한 전체 병동 규모와 기본 외곽을 추정한다.
  - 여러 배치안을 자동 생성한다.

#### B. 그리드 기반 자동배치 모드
- 사용자가 외곽/가능 영역 그리드를 선택한 경우:
  - 해당 그리드 내부에서 자동배치한다.
  - 최소 3개 안을 생성한다.
  - 세 안을 비교 분석할 수 있어야 한다.

### 2. 가능한 모든 영역 채우기
- 자동배치는 가능한 한 영역을 비우지 말고 채워야 한다.
- 특히 외곽 쪽 영역을 최대한 활용해야 한다.
- 남는 공간은 단순 공백이 아니라 다음 중 하나로 분류/활용한다:
  - 지원실
  - 알코브
  - 설비/샤프트 후보
  - 완충/벽체/조인터 영역
  - 중정/void로 의도적으로 비운 영역

### 3. 사후 검사보다 선제적 법규 적합 배치
- 현재처럼 배치 후 rule check에서 많은 오류가 나오는 방식은 지양한다.
- 처음부터 법·가이드라인을 만족하도록 배치 엔진이 제약조건을 반영해야 한다.
- 필요 시 법과 가이드라인은 추가 조사한다.
- 법정 최소값, 국제 가이드라인, 계획 가정, 임시값은 반드시 구분한다.

### 4. 로봇 동선은 후순위
- 로봇 동선은 아직 시기상조이다.
- 우선 자동배치가 안정적으로 작동한 뒤 별도 레이어로 추가한다.
- 현재 v2 범위에서는 로봇 동선을 핵심 제약조건으로 넣지 않는다.

### 5. 청결동선과 감염동선의 물리적 구분
- 청결동선과 감염/오염동선은 물리적으로 분리되어야 한다.
- 두 동선 사이를 오갈 때는 무조건 버퍼 구간을 지나야 한다.
- 버퍼 구간 예:
  - 전실
  - PPE/손위생 버퍼
  - 오염물 임시보관 전이공간
  - 구역 전환 vestibule
- 직접 연결되는 청결-감염 인접은 오류로 처리한다.

### 6. 그리드 크기와 모듈 크기 표시
- 각 그리드의 실제 크기를 표시한다.
  - 기본: 1.8m × 1.8m = 3.24㎡
- 각 모듈의 크기와 면적을 시각적으로 표시한다.
  - 예: R 3×3 cells / 5.4m×5.4m / 29.16㎡ 점유(계획 기준 20.25㎡ 이상)
  - A 2×2 cells / 3.0m×3.0m / 9㎡
  - WC 2×2 cells / 3.0m×3.0m / 9㎡
- hover, legend, export report에 모두 포함한다.

### 7. 병동 모듈 단위 윤곽선
- 병동끼리 붙어 있어도 하나로 뭉쳐 보이지 않도록 한다.
- 2병상 클러스터 또는 병동 모듈 단위마다 윤곽선을 표시한다.
- 윤곽선은 발표용 시각화에서 특히 중요하다.
- 내부 모듈 색상과 별개로 cluster_id/boundary를 관리한다.

## 구현 우선순위 제안

1. `cluster_id`와 2병상 클러스터 템플릿 정의
2. 선제적 constraint-based placement로 rule fail 감소
3. 병상수 입력 기반 무그리드 자동 생성
4. 그리드 기반 3안 생성 및 비교점수화
5. 외곽 채움/잔여공간 분류 알고리즘
6. 청결/감염 구역 그래프 분리 및 버퍼 통과 검증
7. 크기 라벨 및 클러스터 윤곽선 시각화
8. 발표/비교 리포트 export

## 범위 제외

- 로봇 동선은 v2 핵심 범위에서 제외한다.
- 배치 안정화 이후 v3 또는 별도 circulation layer로 추가한다.
